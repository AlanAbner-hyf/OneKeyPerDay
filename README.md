# OneKeyPerDay

#### 项目背景

终身学习！**一天一个知识点！** 不积跬步无以至千里，不积小流无以成江海！！

不论知识点是大还是小，总比一天啥也不干强！

最好是游戏相关的知识点！但如果不是也不必惊讶！

每一个文档保证**手写每一个字符**，不使用AI自动总结！

坏了，现在AI太好用了，保证不了了，不过使用AI总结的会标注出来！

#### 项目结构

Docs：知识点文档内容，使用时间（XXXX年-XX月）进行子文件夹的命名，文档命名规则为时间-知识点（XX日-XX知识点）；

Program：某些知识点涉及到的相关程序，使用程序本身的名称命名，知识点文档中会给相关程序的名称方便寻找；

具体知识点文档需遵循以下结构：

What：知识点概述

Why：为什么今天学习这个知识点

Content：知识点具体内容
